# StayPilot AI

A multi-agentic voice AI hotel concierge and reservation assistant.

## Features

- Multi-agent orchestration using LangGraph
- Hotel reservations and guest service management
- Retrieval-Augmented Generation (RAG)
- Model Context Protocol (MCP) integration
- Four-tier memory architecture
- Real-time voice interaction
- Full-stack web application

## Technology Stack

Python, FastAPI, LangChain, LangGraph, MCP,
Groq, PostgreSQL, Supabase, Qdrant, React,
LiveKit, Deepgram, ElevenLabs, Langfuse,
Docker and AWS ECS.
